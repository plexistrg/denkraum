# Friction First

Denkraum Studio is a **transition tool**, not an archive.

Core direction:
1. Notice friction.
2. Translate friction into concrete form.
3. Execute the next observable action.

## Rules
- Every note must imply action.
- Every practice must have a first grip and repetition cue.
- Research without translation into practice is incomplete.
- Weekly review removes dead weight instead of collecting more text.

## System constraints
- Local-first, single-user flow.
- No account system.
- No cloud sync.
- No external AI or API dependency.
- JSON files only in local `data/` directory.
